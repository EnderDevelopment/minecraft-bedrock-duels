# CubeDuels: Minecraft Bedrock Duels System Addon

CubeDuels is a Minecraft Bedrock addon that introduces a comprehensive duels system with various gamemodes including BedFight, Fireball Fight, Classic, UHC, and Crystal PVP. The addon features a beautiful UI, an animated NPC with a cool skin, and a duel request system. It is designed to enhance the multiplayer experience by providing engaging and competitive game modes.

## Install

1. Download the CubeDuels addon from the GitHub repository or the EnderDevelopment marketplace.
2. Place the downloaded `.mcpack` file in the `resource_packs` folder of your Minecraft Bedrock Edition world.
3. Open Minecraft Bedrock Edition and navigate to the world where you placed the addon.
4. Enable the CubeDuels addon in the resource pack settings.

## Use

1. Spawn the CubeDuels NPC in your world using the provided command or by interacting with a specific block.
2. Interact with the NPC to open the Duels Menu.
3. Select the desired gamemode from the menu.
4. Request a duel with another player by selecting the "Request Duel" option.
5. Accept the duel request from the other player to start the match.
6. Engage in the selected gamemode and enjoy the competitive gameplay.
